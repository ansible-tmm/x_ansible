# Threads Integration

Post to Threads (Meta) using Ansible and the Threads API.

## Authentication

The Threads API uses OAuth 2.0 with long-lived access tokens (60-day expiry).

| Variable | Description |
|----------|-------------|
| `THREADS_APP_ID` | Threads App ID (from Meta Developer Portal) |
| `THREADS_APP_SECRET` | Threads App Secret |
| `THREADS_ACCESS_TOKEN` | Long-lived access token (obtained via setup script) |
| `THREADS_USER_ID` | Your Threads user ID (obtained via setup script) |

## Setup

1. **Create a Meta App** at https://developers.facebook.com/apps
   - Add the "Access the Threads API" use case
   - Note the **Threads App ID** and **Threads App Secret** (under Use cases > Customize > Settings)

2. **Add yourself as a Threads Tester**:
   - In the Meta Developer Portal: App roles > Threads Testers > Add your username
   - Accept the invite in the Threads app: Settings > Account > Website permissions

3. **Set redirect URI** in the portal:
   ```
   https://localhost:8080/callback
   ```

4. **Export credentials**:
   ```bash
   export THREADS_APP_ID="your_threads_app_id"
   export THREADS_APP_SECRET="your_threads_app_secret"
   ```

5. **Run the setup script** to get your access token:
   ```bash
   source venv/bin/activate
   python threads/files/setup_threads_token.py
   ```
   This opens your browser, you authorize the app, and it saves the token to `threads/vars/token.json`.

6. **Alternative**: Use the "User Token Generator" in the Meta Developer Portal to generate a token directly, then:
   ```bash
   export THREADS_ACCESS_TOKEN="your_token"
   export THREADS_USER_ID="your_user_id"
   ```

## Usage

### Post text

```bash
ansible-playbook threads/post_to_threads.yml -e 'post_text="Hello from Ansible!"'
```

### Post with a link

```bash
ansible-playbook threads/post_to_threads.yml \
  -e 'post_text="Check out this automation tool" url="https://example.com"'
```

## How It Works

The Threads API uses a **two-step container publish** flow:

1. **Create container**: `POST /{user_id}/threads` with `media_type=TEXT` and `text=...`
   - Returns a `container_id`
2. **Publish**: `POST /{user_id}/threads_publish` with `creation_id={container_id}`
   - Returns the published `post_id`

The module handles both steps automatically, with a brief pause between for container processing.

## Limitations

- Text posts max: **500 characters**
- Token expires every **60 days** (re-run setup script to refresh)
- Rate limits: ~250 API calls per user per hour
- App must be in development mode (Threads Testers only) until published through App Review
- Link previews are generated by Threads automatically when a `link_attachment` is provided

## Integration with Web UI

Once the token is set up, Threads appears alongside X, LinkedIn, Bluesky, and Reddit in the web UI for AI-powered post generation and publishing.
